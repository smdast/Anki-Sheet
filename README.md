# 暗記シート (Anki-Sheet)

PDF上の指定した色を隠して、指でなぞった部分だけ答えを確認できる暗記ツールです。赤シートで青ペンの文字を隠す感覚を、PDF教材上でそのまま再現します。

ノートやプリントをPDF化してこのアプリで開けば、どんな色のペンで書いた部分でも自由に「隠す色」として指定でき、タップやスワイプといったタッチ操作だけで学習できます。

## 使い方

1. 「PDFを開く」からノートやプリントのPDFファイルを選択します。
2. 「色を選ぶ」をタップし、隠したい文字(青ペンなど)を画面上でタップして色を指定します。
3. 指定した色が自動的に隠れます。画面を指でなぞると、なぞった部分だけ一時的に答えが見えます。

## 主な機能

- **色を指定して隠す** — スポイトで選んだ色(複数指定可)を自動的に検出してマスクします。許容範囲(似た色もまとめて拾うか)も調整できます。
- **隠す色の変更** — マスクの色は黒だけでなく、白・グレー・赤・緑や自由な色に変更できます。
- **指でなぞって確認** — ドラッグした軌跡だけ一時的に答えが見え、指を離すとまた隠れます。
- **軽量なページ送り** — 表示中のページと前後数ページのみを描画・先読みするため、ページ数が多いPDFでも軽快に動作します。
- **ピンチズーム / ダブルタップズーム** — 細かい文字も拡大して確認できます。
- **指定ページへジャンプ** — ページ番号を直接入力して移動できます。
- **縦書き(右綴じ)対応** — ページ送りの向きを反転できる設定があります。
- **タッチ操作優先のUI** — スマートフォン・タブレットでの操作を前提にデザインしています。
- **PWA対応** — ホーム画面に追加してアプリのように起動でき、一度開いたPDFやアプリ本体はオフラインでも利用できます。

## オンラインで使う

GitHub Pages で公開されているバージョンをそのまま開けます。

```
https://smdast.github.io/anki-sheet/
```

スマートフォンでこのページを開き、ブラウザのメニューから「ホーム画面に追加」(Android は「インストール」ボタンも表示されます)を選ぶと、アプリとしてホーム画面から起動できるようになります。

## ローカルで動かす

このアプリは外部サーバーを必要としない単一ページのアプリですが、PWA機能(サービスワーカーによるオフライン対応・インストール)を試す場合は HTTPS または `localhost` 経由で配信する必要があります。

```bash
# リポジトリのルートで
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。

## 技術構成

- 素のHTML / CSS / JavaScript(ビルド不要)
- PDF描画に [PDF.js](https://mozilla.github.io/pdf.js/) を使用
- `manifest.json` と `sw.js` による PWA 対応(アプリ本体と PDF.js をキャッシュし、オフラインでも起動可能)

## ファイル構成

```
.
├── index.html              # アプリ本体
├── manifest.json            # PWAマニフェスト
├── sw.js                     # サービスワーカー(オフラインキャッシュ)
└── icons/                     # ホーム画面用アイコン一式
```

## プライバシー

開いたPDFはすべて端末内(ブラウザ)で処理され、外部サーバーへ送信されることはありません。
